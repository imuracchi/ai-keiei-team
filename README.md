# AI経営チーム

小さな会社の経営者が、経営・営業・財務・組織・事業の専門参謀と相談し、意思決定を記録する試作です。

## 起動

Node.js 22以上で、プロジェクトのフォルダから実行します。追加パッケージのインストールは不要です。

```sh
npm start
```

http://127.0.0.1:3000 を開きます。PORT環境変数でポートを変更できます。

## 現在できること

- 5人の専門参謀の選択、全参謀での検討例
- 共通10問、役職別の質問、会社の方針の入力
- 検討メモの下書き表示
- 本人の決定と理由の記録

## 試作の範囲

**生成AIにはまだ接続していません。** 回答は固定のサンプルで、入力した相談内容を分析する機能はありません。登録した判断軸は参照欄に表示し、サンプル回答への自動反映は行いません。

入力と記録はタブ内のメモリだけに保持し、再読み込みで消えます。サーバー保存、ログイン、企業ごとのデータ分離、資料アップロード、外部送信は未実装です。本番運用には使わず、架空の情報で操作を確認してください。

## 次の実装

1. 認証、会社・利用者・権限のデータモデル
2. サーバー側のAI接続と担当領域別の指示
3. 判断軸・意思決定・会社資料の保存と根拠の参照
4. 本人による成果物の承認と共有

APIキーはサーバーの環境変数に保持し、ブラウザやGitHubに含めない設計にします。

## 検証

```sh
npm test
```

テストは起動したサーバーの正常配信、未許可パスの拒否を確認します。
